# Жанры Unity

[Матрица жанров](GENRE_MATRIX.md) · [Канонические карточки](../Tool_Catalog/INDEX.md).

Каталог охватывает экшен/FPS/TPS, RPG/MMORPG, RTS/4X, симуляторы, гонки, приключения, платформеры, головоломки, менеджмент/строительство, спортивные, idle, VR/AR и гибридные жанры. У каждого жанра будут основные механики, уникальные системы, готовые starter kits, OSS игры, технологии, совместимость и готовые стеки. Наличие строки в матрице пока не означает завершение исследования жанра.
