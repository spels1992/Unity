# Профессиональная карта разработки игр: от А до Я

Это **карта решений**, не «единственно правильная последовательность»: playtest, прототипирование, лицензии и QA повторяются на каждом важном этапе. В каждой строке: **что сделать → что получить → какое готовое средство искать**.

| Этап | Действия и необходимые знания | Результат/зависимость | Готовые средства для поиска |
|---|---|---|---|
| 01 Определение продукта | Идея, гипотеза, аудитория, жанр, референсы, устройства и целевая платформа. | Концепт 1 страница; список аналогов; тестируемые гипотезы. | genre templates, market tools |
| 02 Предпроизводство | GDD/TDD, бюджет, размер команды, роли, риски, реестр ассетов и план лицензий. | GDD; backlog; измеримые KPI/условия успеха. | GDD templates, kanban |
| 03 Выбор готовой основы | Найти готовую игру, полный framework, starter kit, модули, а не писать всё самому. | Шортлист инструментов по лицензии/версии/стоимости. | frameworks, open-source games |
| 04 Прототип и vertical slice | Greybox + главное действие + игровая петля → playtesting → один законченный уровень. | Играбельный прототип и тестовый отчёт. | Unity official microgames, samples |
| 05 Настройка проекта | Выбор Unity Editor LTS, платформа, URP/HDRP/2D, IDE, Git/UPM, лицензия. | Чистый проект, build, lock версий. | Hub, Unity Registry, Git |
| 06 Базовая архитектура | Сцены, префабы, gameplay state, событийная модель, DI при необходимости, сохранения. | Описанная структура и тесты. | ScriptableObjects, DI, event bus |
| 07 Управление и камера | Input System, CharacterController, физика, анимационные переходы, Cinemachine. | Рабочее управление на устройстве. | Starter Assets, Input System, Cinemachine |
| 08 Игровые системы | Combat, stats, quests, inventory, AI, economy, match rules, level systems по жанру. | Тестируемые модули с владельцем состояния. | AI Navigation, RPG systems, combat frameworks |
| 09 Контент и мир | Level design, Blender/2D ассеты, UV, текстуры, риг/анимация, импорт, world streaming. | Список ассетов с лицензией и измерениями. | Blender, Tilemap Extras, Addressables |
| 10 UX/UI/звук | HUD, меню, настройки, туториалы, accessibility, localization, audio. | Проходимый user flow с аудио. | UI Toolkit, Localization, Audio Mixer |
| 11 Сеть и данные | Multiplayer (если нужен), авторитетность сервера, лобби, save migration, backup. | Надёжные сохранения/сетевой протокол. | Mirror, FishNet, NGO, save libraries |
| 12 Контроль качества | Тесты EditMode/PlayMode/функциональные, сборки, crash logs, профайлер, bug triage. | QA checklist и отчёты. | Test Framework, Unity Profiler |
| 13 Оптимизация | Бюджет CPU/GPU, память/GC, texture streaming/LOD, загрузки, профилирование. | FPS/память на целевом устройстве. | LOD, Burst, Jobs, Profile Analyzer |
| 14 Дистрибуция и закон | Лицензии, age rating, платформа, privacy, storefront, signing, CI, релизные notes. | Тестовая и финальная сборки. | Build tools, platform SDK, legal checklists |
| 15 Публикация и поддержка | Release candidate, сообщество, магазины, аналитика, patching, live ops, инциденты. | Публичный релиз, rollback/обновления. | analytics, crash reporting, storefront tools |
| 16 Ретроспектива | Что сработало, что переиспользовать в следующей игре, какие библиотеки заменить. | Обновление этой каталожной базы. | postmortem, reusable project templates |

## Сквозные зависимости
```text
Идея/аудитория → выбор жанра → платформа → технический бюджет
          └→ GDD/риски → поиск готовых решений → прототип
                  ↓                  ↓
          юридический аудит     выбор Unity/рендера
                  └─────────┬─────────┘
                           ▼
                    vertical slice
                           ▼
                производство / QA / тесты
                           ▼
                     build / релиз
                           ▼
                   поддержка / патчи
```
## Универсальные исследовательские вопросы каждого этапа
- **Знания:** какие технические и дизайнерские навыки необходимы?
- **Готовые решения:** существует ли более крупная готовая система вместо набора скриптов?
- **Альтернативы:** официальная бесплатная, внешняя MIT/Apache, бесплатная Asset Store, платная?
- **Автоматизация:** что может делать Unity Editor API, CI, Blender scripts или ИИ-агент без риска?
- **Зависимости:** что должно быть решено раньше (платформа, URP, Input, backend)?
- **Acceptance:** какие конкретные результаты, метрики и тесты подтверждают готовность?

## Следующее углубление
Разбить каждый этап на исследовательские subtasks, конкретные инструменты, 2D/3D/мобильные/VR ответвления и реальные примеры. Ни один пункт пока не объявлен полностью исследованным.
