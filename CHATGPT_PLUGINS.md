# ChatGPT — плагины и скиллы, используемые в работе

Актуализировано: **2026-10-12**. Названия сверены с доступными инструментами ChatGPT и перечнем установленных скиллов. Этот файл — каталог **интеграций в ChatGPT**, а не список Unity/Blender-пакетов или требование устанавливать что-либо на Windows.

| Точное название | Тип / имя инструмента в ChatGPT | Для чего используем |
|---|---|---|
| **Blender MCP** | MCP-плагин `Blender_MCP` | Создание, редактирование, проверка 3D-моделей в Blender. |
| **Context7** | MCP-плагин `Context7` | Поиск актуальной документации библиотек и API для реализации. |
| **FEOM MCP** | MCP-плагин `FEOM_MCP` | Дополнительное управление Windows, окнами и интерфейсом. |
| **Graphify** | Плагин `Graphify` | Поиск символов, анализ графа зависимостей, влияния изменений и связанных тестов в индексированных репозиториях. |
| **Karpathy Guidelines** | Установленный скилл `karpathy-guidelines` (не MCP) | Избегать необоснованных предположений и лишних изменений, ставить проверяемые цели. |
| **Superpowers** | Плагин и набор скиллов `Superpowers` | Планирование, декомпозиция задач, отладка, TDD, ревью и проверка результата. |
| **Unity MCP Server** | MCP-плагин `Unity_MCP_Server` (AnkleBreaker Unity MCP Server) | Управление Unity Editor, сценами, объектами, ассетами и тестами. |
| **Windows MCP** | MCP-плагин `Windows_MCP` | Основной инструмент для Windows, файлов, команд и диагностики. |
| **WinApp MCP** | MCP-плагин `WinApp_MCP` | Второй основной инструмент для управления окнами, UI и приложениями. |

## Как применять

1. **Windows MCP и WinApp MCP — основные компьютерные инструменты.** FEOM MCP — дополнительный, не отменяющий установленные в проекте правила приоритетов и восстановления.
2. **Blender MCP и Unity MCP Server — профильные средства работы в редакторах.** Их доступность в ChatGPT не гарантирует, что локальный редактор или туннель в конкретный момент работает: проверять реальной командой.
3. **Graphify подключён к ChatGPT**, но на дату обновления список его рабочих пространств пуст. Для реального анализа исходников сначала настроить Workspace, привязать нужный репозиторий и дождаться индексации. Не объявлять анализ проведённым без индекса.
4. **Context7** использовать при работе с обновляемыми библиотеками и API; **Superpowers** и **Karpathy Guidelines** — при планировании и проверке качества разработки. Скилл не путать с MCP-сервером.
5. Соблюдать существующие `PROJECT_INSTRUCTIONS.md`, `AGENTS.md` (если есть), правила безопасности, лицензий и **нулевых дополнительных расходов**. **Remote Desktop Commander / Desktop Commander допустим только для восстановления Windows MCP и WinApp MCP** в соответствии с правилами проекта.
6. Этот список **не исчерпывает все приложения в аккаунте**: сюда внесены инструменты, названные владельцем и подтверждённые 2026-10-12. Новые плагины добавлять по мере дальнейших указаний владельца, проверяя точное название и тип.
