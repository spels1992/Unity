# Candidate exclusion: GitHub without usable LICENSE

**2026-10-08: Не используется.**

## wendtcloud/inventory-system
- Кандидат: https://github.com/wendtcloud/inventory-system
- README заявляет MIT и описывает систему drag-drop, stack splitting, merging, Unity 2022.3+.
- При просмотре GitHub tree (24 файла) **не найден отдельный файл LICENSE или COPYING**, metadata license отсутствует.
- Поскольку пользователь требует подтверждённо законно бесплатный и коммерчески применимый инструмент, **BLOCKED_LICENSE_PENDING** до получения текста разрешения/licensing details от автора или обновления лицензии в upstream.
- Наличие публичных исходников и даже строки «MIT» в README без полного текста/ясного copyright notice недостаточно для уверенного соблюдения требований распространения: этот путь не предлагается как используемый стандарт.
- Бесплатная альтернатива с реально прочитанной MIT лицензией: [Unity Modular Inventory System](../Tool_Catalog/unity-modular-inventory.md) (без save), либо [Moonforge RPG Engine](../Tool_Catalog/moonforge-rpg-engine.md) (со связанной RPG domain логикой).

## Подходящие, но только образовательные, не готовые игровые механики
- [Softlight](../Tool_Catalog/softlight-unity6-rpg.md): quests/inventory/combat указаны как planned.
- [OpenKCC](../Tool_Catalog/openkcc-controller.md): версия Unity 6 не тестировалась, upstream старый.
- [Unity FPS Controller](../Tool_Catalog/simple-fps-controller-unity6-mit.md): маленький набор скриптов, не FPS Starter Kit.
- [Edgar Free](../Tool_Catalog/edgar-unity-free.md): PRO platformer/isometric functions платные, не включать.

**Важное отличие:** отсутствие отдельного LICENSE у одного проекта означает «права не подтверждены», а не абсолютный запрет автором. Каталог предпочитает альтернативы с явными проверенными лицензионными условиями.
