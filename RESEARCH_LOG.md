### Достоверные выводы
- Unity 6.3 = LTS, Unity 6.6 = Supported релиз; подтверждено официальными статьями Unity.
- Unity Hub создаёт проекты и устанавливает Editor; Unity Personal имеет условия бесплатного доступа; финансовые пороги/цены меняются.
- Unity излагает особые правила сериализации; prefab instances обладают overrides; порядок одинаковых lifecycle callbacks на разных объектах не гарантируется.
- Git каталог Unity должен сохранять проектные данные и .meta, но игнорировать импортные кэши Library/Temp.
- Unity 6.6 migration имеет изменения Cinemachine 3, которые нельзя игнорировать при обновлении.
- Input System присутствует в официальном каталоге пакетов для Unity 6.3; сторонние библиотеки пока без подтверждённого live-теста.
