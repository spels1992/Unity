# Локальные каталоги AI→Blender — единый стандарт

Актуально: 2026-10-12. Для компьютера разработки на Windows (диск **D:**).

## Куда сохранять результаты

| Генератор | Канонический каталог результатов |
|---|---|
| Stable Fast 3D | `D:\Blender\Stable 3D\3D заготовки` |

**Обязательное правило для всех агентов проекта:** исходные ИИ-заготовки, GLB/OBJ, PNG, текстуры и промежуточные превью складывать в каталог соответствующего генератора. Для каждого объекта/персонажа делать собственную подпапку, например `Koshka-Kartoshka`, `Farm`. Не смешивать заготовки разных генераторов.

**Готовая модель Blender** (мастер-файл .blend и одобренные экспортные ассеты) хранится отдельно в `D:\Blender\Models\<название проекта>`. Не перемещать и не перезаписывать утверждённые модели. После доработки импортировать в Unity только проверенные версии.

## Настройка программ

- Stable Fast 3D установлен отдельно: `D:\Program Files\StableFast3D`. На компьютере `D:\Program Files\StableFast3D\outputs` — NTFS junction на `D:\Blender\Stable 3D\3D заготовки`: старые скрипты продолжают писать в новый каталог. В новых командах явно указывать `--output-dir "D:\Blender\Stable 3D\3D заготовки\<имя объекта>"`.
- Уже полученные файлы Кошки-Картошки из Stable Fast 3D скопированы с проверкой SHA-256. Изолированный SF3D-прототип не является утверждённым каноном; сравнивать с модельным листом и доводить в Blender.
- Если папки отсутствуют, создать их; не менять пути молча и не использовать папку проекта Unity для необработанных моделей.
