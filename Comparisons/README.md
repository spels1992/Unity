# Сравнения

Каждое сравнение содержит одинаковые критерии: крупная готовая система или мелкая библиотека, функции, качество, версия, лицензия, стоимость, FPS/память, риск зависимости, обслуживание, AI automation, дата проверки. Не выдавать результат без тестов за benchmarking.

Начать с: **Mirror vs FishNet vs Netcode for GameObjects**, **Starter Assets vs custom controllers**, **Cinemachine vs manual cameras**, **Unity input/UI**, **2D Tilemap/Level Generation**, **общая RPG architecture**.
