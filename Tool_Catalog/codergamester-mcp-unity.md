# CoderGamester MCP Unity

**ID:** codergamester-mcp-unity · **Категория:** AI/Unity Editor automation · **Жанры:** любые.

- **Назначение:** MCP bridge от AI-клиента к Unity Editor.
- **Готовые функции:** манипуляции GameObjects, команды Editor/MenuItem, IDE интеграции.
- **Официальный GitHub/документация/демо:** https://github.com/CoderGamester/mcp-unity
- **UPM URL по upstream (не применять до проверки прав):** `https://github.com/CoderGamester/mcp-unity.git`.
- **Установка по документации:** Package Manager → Git URL; Tools → MCP Unity → Server Window; локальный Node.js/WebSocket bridge.
- **Лицензия:** MIT, проверен [LICENSE.md](https://github.com/CoderGamester/mcp-unity/blob/main/LICENSE.md).
- **Цена:** исходники бесплатны, сторонний MCP клиент может быть платным.
- **Совместимость Unity:** точная Unity 6000.3 и 6000.6 не тестировалась.
- **Зависимости:** Node.js, Unity Editor package, совместимый MCP client; upstream упоминает порт 8090.
- **Преимущества:** исходники и документация, MIT, расширяемый Editor tool surface.
- **Минусы:** сетевой мост/локальный порт, возможные ошибки синхронизации, **Unity Authorized Agentic Access не подтверждён**.
- **ИИ:** создание/правка сцен, тесты и работа с Console.
- **Итог:** кандидат на пилот только после проверки условий Unity и контролируемой конфигурации доступа.
- **Статус:** README + LICENSE.md, без Editor-тестов.
- **Дата:** 2026-10-08.
