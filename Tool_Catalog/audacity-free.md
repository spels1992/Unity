# Audacity — бесплатная обработка звуков для Unity

- **Назначение:** локальное редактирование, запись, обрезка и экспорт игровых звуков.
- **Официальный сайт:** https://www.audacityteam.org/
- **Исходники:** https://github.com/audacity/audacity
- **Скачать:** https://www.audacityteam.org/download/
- **Версия:** 4.0.1 (официальный changelog, 2026-09-30).
- **Лицензия:** GPLv3 для приложения по upstream README; лицензии внешних материалов проверяются отдельно.
- **Цена:** 0 ₽; `adoption: FREE`, `payment_required: false`, `free_part: локальное редактирование`.
- **Unity:** не UPM пакет; точная версия Unity не требуется. Импорт WAV/OGG в AudioClip в нашем Editor не проверялся.
- **Платформы:** Windows/macOS/Linux; render pipeline не относится к инструменту.
- **Зависимости:** для стандартного WAV workflow платные API и подписки не нужны.
- **Ограничения:** Audacity 4 использует .aup4, старые .aup3 конвертирует; в 4.0.1 отсутствует часть возможностей версии 3, включая старый scripting pipe и Macro Manager. Не полагаться на старые сценарии автоматизации.
- **Как использовать:** собственный или легально полученный звук → локальная обработка → WAV/OGG → отдельный Unity test project → AudioSource/AudioMixer.
- **Преимущества:** бесплатный офлайн-аудиоредактор.
- **Минусы:** переход версии 4 требует переобучения; дополнительные форматы могут требовать FFmpeg.
- **AI:** можно подготовить план обработки и протокол QA, но программное управление Audacity 4 не подтверждено.
- **Оценка:** рекомендуется для звуков и голоса; альтернатива для простой регулировки — встроенный Unity AudioMixer.
- **Статус:** DOCUMENTED / NOT_RUN; `tested: false`; `accessed_at: 2026-10-08`.
- **Источники:** https://www.audacityteam.org/changelog/ ; https://github.com/audacity/audacity ; https://www.audacityteam.org/download/
- **Следующий тест:** на отдельном проекте экспорт WAV и импорт в Unity с проверкой PlayMode и Build.
