# LMMS — бесплатная офлайн-студия игровой музыки

- **ID / теги:** lmms-free, audio, BGM, DAW, soundtrack, cross-platform
- **Задача:** создавать оригинальные музыкальные темы, лупы, боевые и фоновые композиции для Unity без платного API и облака.
- **Готовые функции:** Song Editor, Piano Roll, Beat/Pattern Editor, Mixer, автоматизация, синтезаторы, импорт/экспорт MIDI, поддержка SoundFont2/VST2 (возможности зависят от ОС и конкретного плагина).
- **Официальный сайт / разработчики:** https://www.lmms.io/ — LMMS community.
- **Исходники / загрузка:** https://github.com/LMMS/lmms ; https://www.lmms.io/download ; https://github.com/LMMS/lmms/releases
- **Документация:** https://docs.lmms.io/user-manual/getting-started/installation ; https://docs.lmms.io/user-manual/getting-started/faq
- **Цена / adoption:** 0 ₽, `FREE`; `free_part`: основной редактор, встроенные инструменты; `payment_required: false`; `fallback`: MuseScore Studio для нотной композиции.
- **Лицензия:** GPL-2.0 для приложения (см. upstream GitHub LICENSE). GPL на исходники редактора **не означает**, что оригинальная музыка автоматически GPL. Официальный FAQ разрешает продажу композиций с встроенными инструментами/сэмплами LMMS; внешние SoundFont, VST, записи и семплы проверять по отдельности: https://docs.lmms.io/user-manual/getting-started/faq .
- **Версия:** официальный GitHub Releases показывает **1.2.2 как Latest stable** на 2026-10-08; ветки 1.3 alpha/beta/nightly — не рекомендовать в production без отдельного теста.
- **Unity:** не Unity-пакет; **точной требуемой версии Unity нет**. Выходные WAV/OGG — обычные аудиофайлы для импорта как AudioClip; проверка импорта и loop в конкретном Editor **NOT_RUN**.
- **Платформы / render:** Windows/macOS/Linux; URP/HDRP/Built-in не влияют на создание звука.
- **Зависимости:** для базового сочинения внешние сервисы не требуются; для сторонних VST/SoundFont нужны отдельные совместимые файлы и лицензии.
- **Сочетания:** LMMS → WAV/OGG → Unity AudioClip/AudioSource/AudioMixer. Совместимость форматов документальна, тест в проекте не проводился.
- **Установка:** скачать стабильную сборку с официального сайта, создать собственную мелодию, экспортировать WAV (мастер) или OGG, затем импортировать в отдельный тестовый Unity-проект. **В этом исследовании ничего не устанавливалось.**
- **Demo:** встроенные примеры LMMS есть, но **не** копировать их в игру без проверки авторства/прав конкретного произведения.
- **Плюсы:** бесплатная локальная музыка, паттерны, синтез, автоматизация, отсутствие обязательного API.
- **Минусы:** не замена редактору звукозаписи; некоторые сторонние плагины/семплы могут быть платными или несовместимыми; окончательное звучание/loop надо прослушивать.
- **Поддержка:** upstream активен; дата/версия проверены 2026-10-08.
- **AI automation:** агент может подготовить план BPM/слоёв/длительностей и checklist экспорта; без подтверждённого интерфейса автоматизации **не** заявлять управление LMMS через ChatGPT.
- **Рекомендация:** **основной кандидат** для собственной игровой музыки без дополнительных расходов.
- **Статус:** **изучено по документации / NOT_RUN**; Editor/PlayMode/Build не запускались.
- **accessed_at:** 2026-10-08; **tested:** false.
