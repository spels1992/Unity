# MuseScore Studio — бесплатная нотная редактура для игр

- Назначение: собственные музыкальные темы, MIDI, партитуры, WAV.
- Версия: 4.7.5 (2026-09-08), https://github.com/musescore/MuseScore/releases
- Лицензия приложения: GPL-3.0, https://github.com/musescore/MuseScore
- Стоимость: 0 ₽, бесплатная самостоятельная версия без MuseHub: https://musescore.org/en/download
- Зависимости: локальное приложение; для работы с собственными нотами подписки не нужны. У сторонних звуковых библиотек отдельные условия.
- Unity: экспорт WAV и импорт AudioClip; точная версия Editor не ограничена форматом. Unity 6 тест не выполнялся.
- Сценарий: сочинить собственную тему → WAV → AudioSource в изолированном тестовом проекте → PlayMode/Build проверка.
- Статус: DOCUMENTED, NOT_RUN. Проверено 2026-10-08.
