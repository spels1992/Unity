# TOOL_CARD_TEMPLATE — единая карточка (копировать для нового решения)

```markdown
# <Название> — <категория>

- **ID / теги:** stable-id, жанры, platform, purpose
- **Описание / решаемая задача:** …
- **Что уже готово:** …
- **Официальный сайт / издатель:** URL или «не найден»
- **Upstream GitHub / GitLab:** URL или «не найден»
- **Скачать / Unity Asset Store / UPM:** прямая официальная ссылка или путь; команды только проверенные
- **Документация / демонстрации:** URL
- **Цена:** бесплатно / платно / freemium / неизвестно; валюта, условия, дата
- **Лицензия:** название, файл/URL, коммерческие/redistribution ограничения, степень проверки
- **Unity версии:** конкретные поддерживаемые версии, кем подтверждено
- **Платформы / render pipeline:** Windows/mobile/WebGL/etc, Built-in/URP/HDRP
- **Зависимости:** пакеты/фреймворки и версии
- **Совместимость с другими системами:** подтверждено (источник/тест), предположительно, конфликтует
- **Как установить:** кратко или ссылка на Integration_Guides
- **Примеры / demo scenes / starter project:** официальные ссылки
- **Преимущества:** конкретные, а не маркетинговые
- **Недостатки:** известные, с источниками, и потенциальные (разделять)
- **Поддержка / последнее изменение:** релиз, активность, дата/наблюдение
- **ИИ-автоматизация:** сценарии и ограничения/доступные API
- **Оценка:** рекомендуется / альтернатива / перспективно / устарело / не рекомендуется + причины
- **Статус проверки:** практически проверено / изучено по документации / не проверено
- **Дата и проверявший:** YYYY-MM-DD, имя/инструмент
- **Тесты:** версия Editor, устройство, сценарий, лог; если нет — явно «не тестировалось»
- **Источники:** реальные первоисточники, прямые URL
- **Открытые вопросы/следующий шаг:** …
```

**Правило:** не выдумывать цену, прямой download URL, Unity version или лицензию. Публичный source code без LICENSE нельзя автоматически использовать в закрытой коммерческой игре.

## Обязательный фильтр ZERO COST (2026-10-08)
Новая карточка, даже если найдено уникальное решение, обязана иметь поля:
- `adoption`: FREE | FREE_WITH_LIMIT | RESEARCH_ONLY_PAID | BLOCKED_NO_LICENSE.
- `free_part`: какие именно функции/модели есть бесплатно (например Quaternius Standard 60–70%), нельзя приписывать бесплатной версии Source.
- `payment_required`: строго false для внедряемых решений, включая API/облака/server/CI quota.
- `fallback`: бесплатная некоммерческая или локальная альтернатива, если лимит исчерпан.
- `accessed_at`: дата официальной проверки цены/прав.
- `tested`: только результаты реального Unity/Blender test, а не мнение модели.

Правила: [FREE_ONLY_POLICY](../FREE_ONLY_POLICY.md).
