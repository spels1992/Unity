# CoplayDev MCP for Unity

**ID:** coplaydev-unity-mcp · **Категория:** AI/Unity Editor automation · **Жанры:** все.

- **Назначение:** ассистент через MCP работает с GameObjects, сценами, ассетами, скриптами, тестами и сборками.
- **Готовые функции:** upstream README заявляет 50 MCP tools; список: https://coplaydev.github.io/unity-mcp/reference/tools/.
- **Официальный сайт:** https://coplaydev.github.io/unity-mcp/
- **GitHub:** https://github.com/CoplayDev/unity-mcp
- **Установка по автору (не выполнять до проверки права доступа):** Unity UPM `https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main`, Python 3.10+ и uv MCP bridge.
- **Документация и демонстрация:** README upstream и официальный сайт проекта.
- **Лицензия:** MIT, проверен [LICENSE](https://github.com/CoplayDev/unity-mcp/blob/main/LICENSE).
- **Цена:** open-source пакет бесплатен; дополнительные услуги третьих лиц могут быть платными.
- **Версии Unity:** upstream заявляет 2021.3 LTS–6.x; точная установленная Editor не тестировалась.
- **Зависимости:** Unity Editor, UPM Git, Python/uv, MCP client.
- **Совместимость с другими системами:** не протестирована; **Unity Authorized Agentic Access не подтверждён**.
- **Преимущества:** широкие команды для редактора, MIT, активная разработка (в README релиз v10.3.0 04.10.2026).
- **Недостатки:** условия Unity ToS с 30.06.2026, открытые MCP полномочия, доп. сервер и сетевые риски.
- **ИИ:** организация сцен, тестирование, refactor, сборки — по заявленным возможностям инструмента.
- **Оценка:** перспективно; разрешённый Unity gateway/authorization проверить до любой установки.
- **Статус:** README + LICENSE; **никаких живых тестов**.
- **Дата:** 2026-10-08.
