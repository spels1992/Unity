## Связь с Moonforge
[Moonforge Unity Roguelike Sample](moonforge-rpg-engine.md) заявляет использование 0x72 DungeonTileset II (CC0). Документация sample ссылается на файл Art/DungeonTilesetII/LICENSE.txt, который не был обнаружен в просмотренном GitHub tree по этому пути. **Право на исходный набор теперь проверено у автора**, но точный состав/происхождение встроенных изменённых файлов sample при нашем исследовании отдельно не сверялся. Для новой игры предпочесть получение нужных CC0 sprites прямо с оригинального сайта и фиксировать provenance.
