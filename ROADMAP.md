**Условие для всех фаз:** никакой дополнительной оплаты. Платные решения допускаются исключительно к обзору, adoption блокируется; без скрытых облачных кредитов, billing keys и обязательной платной зависимости. См. [FREE_ONLY_POLICY.md](FREE_ONLY_POLICY.md) и [доступные плагины/скиллы](19_AI_Automation/AVAILABLE_PLUGINS_AND_SKILLS.md).

**Дата изменения концепции: 2026-10-08.** Старый план-энциклопедия архивирован в [Research_Archive](Research_Archive/README.md). Принцип: изучаем готовые решения **раньше, чем пишем собственный код**.

## Условие завершения исследования
Для каждого жизненного этапа и жанра есть исследованные категории; все найденные кандидаты имеют источники, цену/лицензию и статус; наиболее важные решения сравнены с альтернативами; есть готовые связки с реальными тестами; ссылки повторно проверены; новые источники не добавляют существенно полезного. Поиск «буквально всего интернета» невозможен, поэтому используем **насыщение**, явно обозначая неизвестное.

## Правило checkpoint
`поиск → проверка источника → карточка/таблица → коммит → чтение коммита → PROGRESS → следующий шаг`. Непроверенное нельзя выдавать за подтверждённое. Без успешного коммита задача считается незавершённой.
