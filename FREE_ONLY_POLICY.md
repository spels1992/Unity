# Политика бесплатности — обязательное правило проекта Unity и Blender

**Дата:** 2026-10-08. **Инициатор:** владелец проекта «Игрульки». **Принцип:** никакой новой оплаты, подписки, биллинга, кредитов, обязательных покупок или загрузок платных ассетов.

## 1. Что допускается к реальному использованию
**FREE** — бесплатный локальный инструмент, open source (MIT/Apache/BSD/GPL с соблюдением условий), бесплатный официальный Unity package, Asset Store asset с действующей ценой 0 и подходящей лицензией, полностью бесплатная услуга без необходимости платить за базовый workflow.

**INCLUDED** — уже доступный пользователю инструмент ChatGPT/плагин в рамках текущего тарифа, без отдельной оплаты. Не делать его обязательным для разработки: должна существовать воспроизводимая бесплатная альтернатива вне платного сервиса. Тарификация ChatGPT отдельно не называется «полностью бесплатно».

**LIMITED_FREE** — бесплатный тариф с квотами/пробным лимитом: можно оценивать, но **не включать как обязательную часть производства**, если исчерпание лимита останавливает работу или требует оплаты. После квоты предусмотреть бесплатный fallback. Требования регистрации и привязки банковской карты отмечать отдельно.

**RESEARCH_ONLY** — платное, сомнительное, кредиты/ключи/API без подтверждённого бесплатного лимита: **разрешено только исследовать и сравнивать**, не устанавливать и не запускать платные запросы. Можно сохранить карточку для справки, но не рекомендовать к внедрению.

**REJECT** — пиратские копии, нарушающие лицензии, отсутствие необходимого права использования, обязательная платная зависимость без альтернативы, сервис со скрытыми расходами или возможностью непреднамеренного списания.

## 2. Проверка бесплатности перед внедрением
1. Установить **цену именно необходимых функций и лицензии** на официальном сайте на дату проверки.
2. Выяснить, нужны ли аккаунт, карта, платный API key, hosting, GPU credits, Asset Store Pro addon, платная лицензия при росте аудитории.
3. Учесть платные зависимости (генерация 3D/картинок/аудио, облачные базы, серверы, рендер GPU, CI минуты, Git LFS квоты, store fees).
4. Если включается платная функция по умолчанию — отключить. **Не запускать BYOK-провайдеры без достоверного нулевого тарифа**.
5. Для Unity проверить условия **Unity Personal** и финансовые пороги (не обходить лицензию). Для Blender — GPL с соблюдением правил распространения.
6. Сравнить бесплатные альтернативы: self-host, локальный Blender Python, Unity Editor scripts, оффлайн/локальный рендер, GitHub Markdown, бесплатные пакеты.
7. В карточке отмечать: `cash_cost=0`, `pricing_verified_at`, `free_tier_limits`, `requires_card`, `license`, `paid_dependencies`, `fallback`, `status`.

## 3. Правила использования плагинов и скиллов
- Плагины — **инструменты по назначению, а не жёсткие зависимости**. Наличие пакета в ChatGPT не означает, что локальная машина подключена или что его лицензия бесплатна.
- Unity Editor: сначала доступный Unity MCP; если нет связи — разрешённый Windows MCP/ручной/Editor API путь, без попыток обходить условия Unity.
- Blender: `Unity_MCP.blender_bridge` если BlenderMCP addon уже законно подключён; иначе Blender Python / интерфейс через Windows MCP. Любая команда `run_python` выполняется только в явно разрешённом проекте.
- Репозитории/лог результатов: GitHub плагин с checkpoint после каждого блока, при недоступности — локальный Markdown + позднейшая синхронизация только после проверки; **не заявлять GitHub commit пока он не подтверждён**.
- Проверка кода: использовать навыки debugging, testing и verification как рекомендации по рабочему процессу. Не объявлять «всё работает» без тестов.
- Контекст документации: Context7/официальные Unity/Blender API docs; при потере доступа — прямые официальные первоисточники.
- Визуальный дизайн: Figma/Canva/Adobe Express — только в пределах реально бесплатных возможностей; не привязывать арт-пайплайн к платным облакам. Blender, Krita/GIMP/Inkscape — оффлайн бесплатные альтернативы.
- **Тарифные и квотные сервисы:** Magnific, OpenArt, облачные генераторы Unity `generate_image/generate_model/generate_audio`, fal.ai/OpenRouter/Tripo/Meshy и платный хостинг — по умолчанию `RESEARCH_ONLY` до отдельного подтверждения нулевых расходов.

## 4. Стандарт решения о принятии
Инструмент готов к внедрению только если:
`(лицензия законна) AND (доступ реально бесплатен) AND (нет скрытой обязательной оплаты) AND (версии подходят) AND (тест либо отмечен как не проведённый) AND (есть план отката)`.

**Приоритет**: поддерживаемый бесплатный цельный starter kit → бесплатный фреймворк → бесплатная подсистема → бесплатная библиотека → собственный код. Платный вариант не является обязательной альтернативой и не может останавливать разработку.

## 5. Что считается результатом
Каталог может включать карточки платных продуктов для сравнительного исследования, но их `adoption=blocked_paid`; в [BEST_SOLUTIONS](BEST_SOLUTIONS.md) для использования продвигаются **только бесплатные варианты** с проверенными условиями.
