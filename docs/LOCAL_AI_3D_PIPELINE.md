# Локальный конвейер производства 3D и анимаций

**Все работы выполняются локально. В GitHub сохранять только при отдельном прямом задании владельца.**

1. **МОДЕЛЬ — скилл 3D Craft**, ID 3d-craft, в интерфейсе 3D Craft — 3Д Крафт; в поддерживаемом интерфейсе вызвать @3d-craft. Сначала уточнить референс и анатомию, затем локальный Stable Fast 3D → GLB → сборка и локальное исправление в Blender → минимум 42 ракурса независимой визуальной проверки. Не реконструировать хорошие модели примитивами и не менять оригинал без резервной копии. Для животных Фермы реалистичный силуэт, копыта, голова, рога, суставы и текстуры проверяются до костей.
2. **СКЕЛЕТЫ И АНИМАЦИИ — скилл Bones**, технический ID установленного скилла **rig-motion**; на момент проверки интерфейс установленного плагина пока показывает **Rig**, поэтому фактический вызов @Rig. Вызов @Bones использовать только после проверки, что это имя появилось в интерфейсе. Не имитировать активацию по написанному названию. Для органики — SkinTokens CPU, если подходит, либо модульный скелет Blender, правка весов, полный комплект игровых клипов, циклы/контакты/деформации, 42 ракурса QA и реальные проверки в Unity.
3. **ПОРЯДОК:** сначала модель прошла визуальное качество и получила APPROVED, потом скелет и анимация, только потом интеграция в Unity. Не признавать успешной модель, не похожую на референс, даже если анимация работает.
4. **ПУТИ:** результаты Stable Fast 3D — D:\Blender\Stable 3D\3D заготовки; сохранённые исходники и исправленные модели — D:\Blender\Models, в собственных папках проекта. Без переустановок, новых затрат и сторонних платных генераторов без согласования.
5. **ГИГИЕНА:** после любой операции каждый агент обязан закрыть свои временные окна и процессы. Читать PROCESS_HYGIENE.md; оставленные терминалы запрещены.
