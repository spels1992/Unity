**Актуальная инструкция: 2026-10-13. Создание и переработка 3D-моделей — только через [3D Craft](https://chatgpt.com/plugins/plugins_6acdc74c86888191b2101b657a2e8f8d) и [docs/3D_CRAFT.md](3D_CRAFT.md). Бюджет дополнительных расходов: 0 ₽.**

> Сведения о ComfyUI ниже оставлены **только как справка о ранее установленной программе**; они не разрешают использовать его в 3D Craft. Установка SF3D исторически проверялась по частям; фактическое выполнение каждой новой генерации и качество полученного GLB проверять отдельно.

## Проверенные имена и пути на компьютере Windows

| Инструмент | Назначение | Путь |
|---|---|---|
| **ComfyUI** (имеется, **не используется для 3D Craft**) | Справочно для задач вне 3D Craft | `D:\Program Files\ComfyUI\ComfyUI_windows_portable\ComfyUI\main.py` |
| Python ComfyUI | Изолированное окружение программы | `D:\Program Files\ComfyUI\ComfyUI_windows_portable\python_embeded\python.exe` |

| **Stable Fast 3D (SF3D)** от Stability AI | **Image-to-3D**: строит текстурированную 3D-сетку **из изображения**, а не непосредственно из текстового промпта | `D:\Program Files\StableFast3D\source\run.py` |
| Python SF3D | Отдельное окружение Python 3.10 / PyTorch CUDA 12.1 | `D:\Program Files\StableFast3D\.venv\Scripts\python.exe` |

**Важно:** программы обнаружены на **D:**, не в `C:\Program Files`. Не перемещать без проверки зависимостей и явной необходимости. Эти программы установлены глобально отдельно от канонических каталогов Unity (`D:\Unity\`) и Blender (`D:\Blender\`).

## Фактический статус — не выдавать частичную установку за готовность

- **ComfyUI: установлен, локальный API работает**, проверен `http://127.0.0.1:8188/system_stats`, CUDA видит NVIDIA RTX 4060 8 ГБ. Установка ComfyUI **не гарантирует**, что необходимые checkpoints, генераторы 3D и custom nodes уже скачаны.
- **Stable Fast 3D: исходники, виртуальная среда, CUDA PyTorch и основные Python-библиотеки присутствуют**; проверка их импорта прошла. **Исторический статус на 2026-10-12**: на тот момент генерация GLB не была подтверждена в данном документе. Теперь используется локальный `Run-SF3D.cmd` с установленной моделью; перед каждым новым запуском проверять файл, логи, exit code и визуальную целостность полученного GLB, не считать предыдущий успех доказательством текущего.
- Проверка доступности ComfyUI из PowerShell (без нового запуска): `Invoke-RestMethod -Uri 'http://127.0.0.1:8188/system_stats' -TimeoutSec 5`. Не открывать веб-UI и окна при фоновых задачах.
- Не записывать HF/API-токены в исходники, логи или GitHub. Не пользоваться платными внешними API по умолчанию.

## Обязательный производственный маршрут при создании и переработке 3D-моделей

**Перед началом агент обязан загрузить 3D Craft**: [главная инструкция](3D_CRAFT.md), [плагин](https://chatgpt.com/plugins/plugins_6acdc74c86888191b2101b657a2e8f8d). Если навыка нет в текущем сеансе — `BLOCKED`, не объявлять его применённым и не переключаться на старый ComfyUI-маршрут.

1. **Референс:** взять утверждённое изображение либо сгенерировать изображение напрямую; сохранить оригинал. ComfyUI и Rodin не применять.
2. **Генерация:** подтвердить доступ к Windows MCP и `D:\Program Files\StableFast3D\Run-SF3D.cmd`, сохранить PNG в `inputs`, запустить один SF3D CUDA-прогон, проверить логи/GLB. SF3D — одна картинка за запуск, не настоящая автоматическая multi-view реконструкция.
3. **Сборка:** в Blender MCP держать удачную базовую форму, отдельно создавать/оценивать варианты дефектной части или аксессуара, примерять и менять только плохой участок; исходник/backup сохранять. Проверять 42 ракурса и крупные планы после каждой принятой правки, исправлять критические/серьёзные дефекты до готовности.
4. **Unity / 2D:** если ассет предназначен для игры, импортировать и реально проверять масштаб, шейдеры, анимации, коллизии и производительность. Для 2D/изометрии при необходимости получать спрайты из проверенного 3D. Нет реального теста — `NOT_TESTED`.
5. **Приёмка:** соблюдать стиль проекта, права/лицензии, запрет платежей и арт-гейты; сохранять исходный PNG, GLB кандидатов, .blend, 42 review, финальный экспорт и журнал дефектов. Не заменять утверждённые ассеты без нужных согласований.

## Требования по стилю и затратам

- **Никаких мультяшных, игрушечных, неоправданно круглых или одинаковых клонов** в финальном оформлении «Фермы». Привычная читаемость изометрии, взрослые реалистичные материалы и правдоподобная анатомия; не копировать чужие игровые ассеты.
- Проверять расходы: локальный SF3D не имеет оплаты за каждый запуск, но сторонние модели/сервисы могут иметь лицензии и платные узлы. ComfyUI для 3D Craft не используется. Не переключаться на облачные платные endpoint без разрешения.
- Для SF3D проверять **Stability AI Community License** и условия gated-весов отдельно; лицензия самого ComfyUI и лицензии моделей — разные вещи.
- Сохранять исходное изображение, настройки SF3D, версии/кандидаты частей, хеш, BLEND, 42 вида QA, финальный GLB/спрайты и сведения о лицензии. Только при реальном успешном запуске помечать этап **PASS**; иначе **BLOCKED / NOT_TESTED**.

## Специально для общей Unity-библиотеки

При самостоятельном создании или переработке 3D-модели для Unity использовать 3D Craft (прямой референс → локальный SF3D → Blender/42 ракурса → Unity). После экспорта обязательны реальные импорт, материалы, масштаб, LOD/rig/анимации/коллизии и тесты в целевом Unity-проекте. Для исследования и интеграции готовых пакетов использовать существующие руководства и лицензионные ограничения.
