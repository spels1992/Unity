# Локальный ИИ-конвейер моделей — ComfyUI + Stable Fast 3D (SF3D)

**Обновлено: 2026-10-12. Обязательный инструментальный маршрут при работе с подходящими новыми игровыми 3D-ассетами. Бюджет дополнительных расходов: 0 ₽.**

## Проверенные имена и пути на компьютере Windows

| Инструмент | Назначение | Путь |
|---|---|---|
| **ComfyUI** (официальная portable-сборка NVIDIA, CUDA 12.6) | Локальный граф генерации ИИ-изображений/текстур и оркестрации подключённых моделей | `D:\Program Files\ComfyUI\ComfyUI_windows_portable\ComfyUI\main.py` |
| Python ComfyUI | Изолированное окружение программы | `D:\Program Files\ComfyUI\ComfyUI_windows_portable\python_embeded\python.exe` |
| Запуск ComfyUI без окна | Фоновый локальный сервер | `D:\Program Files\ComfyUI\Start-ComfyUI-Silent.ps1` |
| **Stable Fast 3D (SF3D)** от Stability AI | **Image-to-3D**: строит текстурированную 3D-сетку **из изображения**, а не непосредственно из текстового промпта | `D:\Program Files\StableFast3D\source\run.py` |
| Python SF3D | Отдельное окружение Python 3.10 / PyTorch CUDA 12.1 | `D:\Program Files\StableFast3D\.venv\Scripts\python.exe` |

**Важно:** программы обнаружены на **D:**, не в `C:\Program Files`. Не перемещать без проверки зависимостей и явной необходимости. Эти программы установлены глобально отдельно от канонических каталогов Unity (`D:\Unity\`) и Blender (`D:\Blender\`).

## Фактический статус — не выдавать частичную установку за готовность

- **ComfyUI: установлен, локальный API работает**, проверен `http://127.0.0.1:8188/system_stats`, CUDA видит NVIDIA RTX 4060 8 ГБ. Установка ComfyUI **не гарантирует**, что необходимые checkpoints, генераторы 3D и custom nodes уже скачаны.
- **Stable Fast 3D: исходники, виртуальная среда, CUDA PyTorch и основные Python-библиотеки присутствуют**; проверка их импорта прошла. **Генерация GLB пока НЕ ПОДТВЕРЖДЕНА**: официальный Windows-путь экспериментальный, нативные `texture_baker` и `uv_unwrapper` требуют сборки, доступ к весам `stabilityai/stable-fast-3d` на Hugging Face может требовать принятия лицензии и личного токена.
- Проверка доступности ComfyUI из PowerShell (без нового запуска): `Invoke-RestMethod -Uri 'http://127.0.0.1:8188/system_stats' -TimeoutSec 5`. Не открывать веб-UI и окна при фоновых задачах.
- Не записывать HF/API-токены в исходники, логи или GitHub. Не пользоваться платными внешними API по умолчанию.

## Обязательный производственный маршрут при создании новых моделей

1. **Выбрать исходный метод.** Если новый визуальный объект целесообразно генерировать ИИ, сначала проверить локальный ComfyUI и возможность получения референса/изображения из **бесплатной локальной модели**; использовать имеющийся законный референс, когда генератор изображений ещё не настроен.
2. **Оценить SF3D.** Для подходящих статичных объектов попробовать реконструкцию по изображению через **Stable Fast 3D**, только после успешной проверки весов, native extensions и тестового GLB. Не заявлять об успешной 3D-генерации на основании существования `run.py`. Для сложных анимированных персонажей/шерсти/тонких ветвей SF3D может дать плохую топологию: разрешено моделировать непосредственно в Blender или использовать другие законные бесплатные методы.
3. **Доработать в Blender.** Исправить анатомию, пропорции, силуэт, сетку/ретопологию, UV, PBR, масштаб, LOD, коллизии, риг/анимацию по необходимости; хранить авторские исходники и документировать источник.
4. **Проверить в Unity.** Импортировать `GLB/FBX` или запечь спрайты для 2D/изометрии; проверить сцену, вид сверху, тени, масштаб, fps/нагрузку, взаимодействия, EditMode/PlayMode. Не подменять реальные Unity-тесты скриптовой имитацией.
5. **Приёмка.** Проверить лицензию источника/ИИ-модели/результата, сохранить право использования и SHA, визуально сравнить с утверждённым стилем. Не заменять действующие ассеты экспериментальными без QA и утверждения владельца; после каждого этапа коммит, SHA и отчёт.

## Требования по стилю и затратам

- **Никаких мультяшных, игрушечных, неоправданно круглых или одинаковых клонов** в финальном оформлении «Фермы». Привычная читаемость изометрии, взрослые реалистичные материалы и правдоподобная анатомия; не копировать чужие игровые ассеты.
- Проверять расходы: локальные ComfyUI/SF3D не имеют оплаты за каждый запуск, но сторонние модели/сервисы могут иметь лицензии и платные узлы. Не переключаться на облачные платные endpoint без разрешения.
- Для SF3D проверять **Stability AI Community License** и условия gated-весов отдельно; лицензия самого ComfyUI и лицензии моделей — разные вещи.
- Сохранять исходное изображение, промпт/workflow, версию модели, хеш, BLEND, финальный GLB/спрайты и сведения о лицензии. Только при реальном успешном запуске помечать этап **PASS**; иначе **BLOCKED / NOT_TESTED**.

## Специально для общей Unity-библиотеки

При подборе решений для художественного производства включать локальный ComfyUI и Stable Fast 3D в **первичную проверку доступных бесплатных средств**. Они служат инструментами подготовки ассетов, а не заменяют Unity Editor/Unity MCP или репозиторий Unity. Готовые Mesh/GLB/FBX экспортировать через Blender, импортировать с контролем нормалей, материалов, UV, LOD, коллизий, FPS и платформенных бюджетов. Для изометрических игр сохранять единый угол камеры и запекать согласованные sprite atlases. Запись инструментов в библиотеку не означает успешное тестирование нативного SF3D на Windows.
