# 3D-риггинг и анимации: готовые скиллы ChatGPT, Blender и Unity

Установленные наборы упакованы из **оригинальных инструкций GitHub**. При их применении пользоваться доступными **Blender MCP** и **Unity MCP Server**. Скиллы — справочные инструкции для агента; они **не являются** отдельным MCP-сервером, генератором костей/анимаций, библиотекой готовых клипов или пакетом Unity. Иконки уже заданы на страницах обоих плагинов. Наборы пересекаются — выбирать нужные навыки по задаче, а не пытаться без разбора применять все 111 скиллов.

## Обязательный производственный маршрут

1. **Референс и назначение модели.** Для людей (мужчина/женщина), зомби, боссов, кабанов/оленей и птиц определить анатомию, камеру, нужные действия и видоспецифичную механику. Пригодность исходных моделей или готовых анимаций проверять до скачивания, лицензии хранить вместе с источниками.
2. **Создание/очистка 3D-модели.** При применимости: бесплатные локальные ComfyUI → Stable Fast 3D (**только при подтверждённом успешном GLB**) → Blender MCP. Проверить сетку, масштаб, normals, суставные петли, разделение жёстких и деформируемых деталей. Канонический исходник не перезаписывать.
3. **Проектирование скелета.** Для гуманоидов — пропорциональная иерархия и подходящий Humanoid; для животных — реальные суставы, плечевой пояс, лапы/копыта, позвоночник, хвост; для птиц — отдельная система костей крыльев и хвоста; для необычных боссов — индивидуальная иерархия. **Не копировать человеческий скелет механически на животных.**
4. **Skinning и контрольные позы.** Нормализовать веса, проверить deform-bones и ограничения; протестировать крайние положения каждой конечности, суставы, одежду/панцирь, пересечения, растяжения и подвешенные вершины. Автоматические веса — заготовка, а не конечное качество.
5. **Движения и ретаргетинг.** Искать бесплатные легальные библиотеки готовых клипов, убедиться в совместимости rig/rest pose, лицензиях, осях и root; иначе создавать/корректировать Actions через Blender MCP, IK/FK и ключевые позы. Раздельно проверять шаг/бег/галоп, рывок/атаку/смерть, полёт/взлёт/приземление.
6. **Качество движения.** Проверить контакт с полом, foot sliding, скорость/ускорение, отсутствие рывков на швах циклов, естественность биомеханики, понятность атаки в игровой камере. Для босса: подготовка → удар → восстановление; для птиц: фазы взмаха и складывание крыла.
7. **Запекание, экспорт, повторный импорт.** Сохранять Actions, проверять frame rate, local axes и root motion. Экспорт FBX/GLB через Blender MCP; чистый повторный импорт в Unity MCP. Unity **Humanoid** — для подходящих людей/зомби, **Generic** — обычно для кабанов, оленей, птиц и необычных боссов.
8. **Проверка конечного игрового представления.** Unity Animator, Blend Trees/transition, инспекция Avatar, ошибки консоли, производительность. Для изометрической 2D игры «Ферма» при необходимости **рендерить 3D-движения в 2D-спрайт-листы** и тестировать реальные углы камеры. Не менять 2D концепцию игры на 3D без отдельного решения.
9. **Результаты в GitHub.** Хранить скрипты, документы, ссылки, тесты и метаданные источников. Тяжёлые чужие ассеты, исходные веса ИИ, кэши и объёмные временные модели без обоснования в репозитории не размещать.

## Инструменты, которые пока только кандидаты, а не установленные ChatGPT-плагины

- [Animal Animator](https://extensions.blender.org/add-ons/animal-animator/) — отдельное расширение Blender, экспериментальное; не объявлять установленным без живой проверки.
- [UniRig](https://github.com/VAST-AI-Research/UniRig) и [SkinTokens](https://github.com/VAST-AI-Research/SkinTokens) — модели генерации **скелета и весов**, не полного набора анимаций; нужны отдельные GPU/лицензионные/производительные тесты. Наличие исследовательского кода не означает готовый ChatGPT MCP.
- [Quaternius](https://quaternius.com/) и [Mesh2Motion](https://github.com/Mesh2Motion/mesh2motion-app) — внешние источники и инструменты движений; отдельно проверять реальное наличие бесплатного пакета, лицензии, ретаргетинг и экспорт.

**Обязательное правило:** документация/скилл ≠ успешно протестированная операция. При любых изменениях геометрии/костей/клипов требуются реальные проверки в Blender и Unity; бесплатность чужих клипов/моделей подтверждать отдельно.
