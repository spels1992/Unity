# AGENTS.md — обязательная точка входа ИИ в Unity

## Перед созданием или правкой 3D-моделей — 3D Craft

**Любая новая либо изменяемая собственная 3D-модель (включая одежду, аксессуары, детали и игровые объекты) делается через [3D Craft](https://chatgpt.com/plugins/plugins_6acdc74c86888191b2101b657a2e8f8d) (`3d-craft`).** Прежде чем что-либо менять, прочитать [docs/3D_CRAFT.md](docs/3D_CRAFT.md) и [PROJECT_INSTRUCTIONS.md](PROJECT_INSTRUCTIONS.md), затем проверить, что этот скилл действительно подключён. Название `@3d-craft` не гарантирует подключения. При отсутствии скилла — `BLOCKED` с предложением подключить его, без самовольной подмены технологии.

Прямое изображение → локальный Stable Fast 3D → версии GLB → сравнение/сборка в Blender MCP и QA 42 ракурсов → импорт/реальные тесты через Unity MCP. ComfyUI/Rodin не применять внутри 3D Craft. Не разрушать утверждённые модели и Unity-сцены: backup, отдельные версии, один агент-писатель, краткие сообщения о прогрессе. Для независимых задач привлекать агентов с той же моделью и мощностью, если доступно.

Для **не-3D** задач (код, игровые механики, поиск решений, интеграция чужих пакетов) продолжают действовать [PROJECT_INSTRUCTIONS.md](PROJECT_INSTRUCTIONS.md), [WORKFLOW_AND_PATHS.md](WORKFLOW_AND_PATHS.md), [LOCAL_ASSET_PATHS.md](LOCAL_ASSET_PATHS.md), правила лицензий и тестов.
