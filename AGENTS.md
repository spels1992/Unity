## 🚨🚨 КРИТИЧЕСКОЕ ПРАВИЛО ОКОН: ВСЕГДА ЗАКРЫВАТЬ

**МАКСИМАЛЬНЫЙ ПРИОРИТЕТ ДЛЯ КАЖДОГО АГЕНТА И СУБАГЕНТА.** Открыл Блокнот, картинку, папку, приложение, браузер, PowerShell, CMD, Blender, Unity или временный фоновый процесс → поработал → ЗАКРЫЛ → проверил отсутствие своего временного окна и PID. Делать сразу после каждого этапа, включая сбои; скрытие/сворачивание не считается закрытием. Не оставлять мусор, не затрагивать пользовательские окна и постоянные MCP-службы. **Обязательно прочитать [docs/PROCESS_HYGIENE.md](docs/PROCESS_HYGIENE.md).** В отчёте: CLOSED / PRESERVED / BLOCKED; незакрытый свой процесс = NOT READY.

## 🚨 3D-МОДЕЛИ И АНИМАЦИИ — РАЗНЫЕ ОБЯЗАТЕЛЬНЫЕ СКИЛЛЫ

**Модель:** 3D Craft (3d-craft, @3d-craft) → Stable Fast 3D → Blender QA 42 ракурса и проверка анатомии. **Кости и анимации:** Bones = технический скилл rig-motion, сейчас отображается Rig / @Rig; @Bones только после подтверждённого переименования. Использовать SkinTokens CPU при пригодности, затем проверять движения в Unity. Сначала одобрить качество модели, затем создавать rig; не принимать мультяшную подмену реалистичного животного. Подробности: [docs/LOCAL_AI_3D_PIPELINE.md](docs/LOCAL_AI_3D_PIPELINE.md). Результаты локально, без GitHub push без явного нового поручения.


## Перед созданием или правкой 3D-моделей — 3D Craft

**Любая новая либо изменяемая собственная 3D-модель (включая одежду, аксессуары, детали и игровые объекты) делается через [3D Craft](https://chatgpt.com/plugins/plugins_6acdc74c86888191b2101b657a2e8f8d) (`3d-craft`).** Прежде чем что-либо менять, прочитать [docs/3D_CRAFT.md](docs/3D_CRAFT.md) и [PROJECT_INSTRUCTIONS.md](PROJECT_INSTRUCTIONS.md), затем проверить, что этот скилл действительно подключён. Название `@3d-craft` не гарантирует подключения. При отсутствии скилла — `BLOCKED` с предложением подключить его, без самовольной подмены технологии.


Для **не-3D** задач (код, игровые механики, поиск решений, интеграция чужих пакетов) продолжают действовать [PROJECT_INSTRUCTIONS.md](PROJECT_INSTRUCTIONS.md), [WORKFLOW_AND_PATHS.md](WORKFLOW_AND_PATHS.md), [LOCAL_ASSET_PATHS.md](LOCAL_ASSET_PATHS.md), правила лицензий и тестов.
