## Универсальное правило запуска и ремонта программ — 16.10.2026

**При разрешённой порученной работе агент сам запускает все необходимые закрытые установленные программы** (Unity, Blender, Hunyuan3D-2GP, SkinTokens и другие), сверяясь с [единым справочником абсолютных путей](https://github.com/spels1992/Farm/blob/main/docs/TOOL_STARTUP_AND_MCP_RECOVERY_RU.md). Если MCP/CLI не отвечает: диагностирует конкретный сбой, выполняет адресное исправление, повторно проверяет реальную функцию и продолжает исходную задачу. **После первой неудачной диагностики останавливаться запрещено.** Если осмысленные попытки не помогли, сохранить лог и checkpoint, самостоятельно взять другую разрешённую задачу, а не объявлять всю разработку заблокированной.

Это не разрешение на защищённые OWNER_ONLY 3D/rig/animation, повторное включение намеренно удалённого Farm Watcher/туннеля или автозапуск GUI монитором. Не запускать второй Unity на одном проекте и не уничтожать несохранённую работу.

## Перед созданием или правкой 3D-моделей — 3D Craft

**Любая новая либо изменяемая собственная 3D-модель (включая одежду, аксессуары, детали и игровые объекты) делается через [3D Craft](https://chatgpt.com/plugins/plugins_6acdc74c86888191b2101b657a2e8f8d) (`3d-craft`).** Прежде чем что-либо менять, прочитать [docs/3D_CRAFT.md](docs/3D_CRAFT.md) и [PROJECT_INSTRUCTIONS.md](PROJECT_INSTRUCTIONS.md), затем проверить, что этот скилл действительно подключён. Название `@3d-craft` не гарантирует подключения. При отсутствии скилла — `BLOCKED` с предложением подключить его, без самовольной подмены технологии.


Для **не-3D** задач (код, игровые механики, поиск решений, интеграция чужих пакетов) продолжают действовать [PROJECT_INSTRUCTIONS.md](PROJECT_INSTRUCTIONS.md), [WORKFLOW_AND_PATHS.md](WORKFLOW_AND_PATHS.md), [LOCAL_ASSET_PATHS.md](LOCAL_ASSET_PATHS.md), правила лицензий и тестов.


## Новый 3D Craft — обязательный четырёхракурсный процесс

Создание 3D: единый согласованный sheet с 4 ортографическими ракурсами (front, back, left, right) → crop в 4 отдельных PNG → локальный Codex Desktop MCP **hunyuan3dLocal** (Hunyuan3D-2GP / 2mv Turbo) → GLB в D:\AI-MCP\hunyuan-local\jobs\<job_id>\result.glb → Blender QA/раскраска → Unity QA. При одиночном фото сначала создать один **единый** лист, а не независимо генерировать четыре картинки. Локальная установка D:\Program Files\Hunyuan3D-2GP; окружение .venv, веса models-local и models-cache; MCP D:\AI-MCP\hunyuan-local\hunyuan_mcp.py. В ChatGPT Windows UI основной инструмент WinApp MCP; Desktop Commander только диагностика и ремонт WinApp. Модель пока выводится без текстур, цвет делается отдельным проверенным этапом Blender. Старые реальные файлы не удалять.
