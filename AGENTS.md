# AGENTS.md — обязательная точка входа ИИ в Unity

## 🚨🚨 КРИТИЧЕСКОЕ ПРАВИЛО: ЗАКРЫВАЙ ВРЕМЕННЫЕ ОКНА, СОХРАНЯЙ РАБОЧИЕ ИНСТРУМЕНТЫ

**Действует во всех чатах и задачах, работающих с репозиториями игр и программ; это не ограничение только для ежечасной автоматизации.** Закрывай после работы собственные временные окна и промежуточный мусор: CMD/PowerShell, блокноты, редакторы, открытые для разового просмотра, просмотрщики изображений/видео, окна Проводника и подобные вспомогательные окна. Проверяй, что окно принадлежит текущей задаче; не трогай окна пользователя и других задач.

**Не закрывай рабочие приложения и инструменты:** Unity, Blender, Fast 3D, Windows MCP, WinApp MCP и другие используемые MCP-инструменты, их серверы и туннели. При необходимости их можно свернуть, оставив работающими. Подробный порядок и отчётные статусы: [docs/PROCESS_HYGIENE.md](docs/PROCESS_HYGIENE.md).

**Запрет на запись/публикацию в GitHub действует только для ежечасных автоматизированных задач.** В обычных чатах GitHub не запрещён: выполняй нужные операции в рамках конкретного поручения пользователя.

## 🚨 ПРОВЕРЕННЫЕ ЛОКАЛЬНЫЕ ПУТИ И ПОЛНЫЙ 3D-КОНВЕЙЕР

**Перед работой с Stable Fast 3D, SkinTokens, Blender или Unity обязательно открыть [docs/LOCAL_3D_PRODUCTION_PATHS.md](docs/LOCAL_3D_PRODUCTION_PATHS.md).** Там указаны проверенные пути установок и результатов, последовательность референс → 3D Craft → Stable Fast 3D → Blender QA → Bonix/SkinTokens CPU → анимации → Unity QA. Если локальные инструменты в текущем окружении отсутствуют, не притворяться, что диск D: доступен.

## 🚨 3D-МОДЕЛИ И АНИМАЦИИ — РАЗНЫЕ ОБЯЗАТЕЛЬНЫЕ СКИЛЛЫ

**Модель:** 3D Craft (3d-craft, @3d-craft) → Stable Fast 3D → Blender QA 42 ракурса и проверка анатомии. **Кости и анимации:** Bonix (bonix / @Bonix; прежние Rig/Rig Motion/Bones — устаревшие названия). Использовать SkinTokens CPU при пригодности, затем проверять движения в Unity. Сначала одобрить качество модели, затем создавать rig; не принимать мультяшную подмену реалистичного животного. Подробности: [docs/LOCAL_AI_3D_PIPELINE.md](docs/LOCAL_AI_3D_PIPELINE.md). Результаты фиксируй локально. Ограничение на GitHub push действует только для ежечасных автоматизированных задач; в обычных чатах выполняй нужные GitHub-операции в рамках конкретного поручения пользователя.


## Перед созданием или правкой 3D-моделей — 3D Craft

**Любая новая либо изменяемая собственная 3D-модель (включая одежду, аксессуары, детали и игровые объекты) делается через [3D Craft](https://chatgpt.com/plugins/plugins_6acdc74c86888191b2101b657a2e8f8d) (`3d-craft`).** Прежде чем что-либо менять, прочитать [docs/3D_CRAFT.md](docs/3D_CRAFT.md) и [PROJECT_INSTRUCTIONS.md](PROJECT_INSTRUCTIONS.md), затем проверить, что этот скилл действительно подключён. Название `@3d-craft` не гарантирует подключения. При отсутствии скилла — `BLOCKED` с предложением подключить его, без самовольной подмены технологии.


Для **не-3D** задач (код, игровые механики, поиск решений, интеграция чужих пакетов) продолжают действовать [PROJECT_INSTRUCTIONS.md](PROJECT_INSTRUCTIONS.md), [WORKFLOW_AND_PATHS.md](WORKFLOW_AND_PATHS.md), [LOCAL_ASSET_PATHS.md](LOCAL_ASSET_PATHS.md), правила лицензий и тестов.
